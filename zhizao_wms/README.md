# 智造WMS · 仓储库存与智能补货预警系统

面向制造现场的轻量仓储工作台，围绕四个动作组织：看库存、识别风险、记录流水、追溯关联。

## 核心模块

1. **库存驾驶舱**：查看物料总量、库存总量和当前库存分布。
2. **补货预警中心**：按照当前库存阈值输出补货优先级。
3. **出入库流水台**：登记入库、出库并自动同步物料当前库存。
4. **单据 OCR 入库**：上传出入库单据，识别仓库/部门、物料和数量后核对入库。
5. **库存关联查询**：从仓库/部门反查物料流水，也可从物料反查使用位置。

## 预警口径

- 🔴 当前库存 `< 10,000`：紧急备货（高风险）
- 🟡 `10,000 ≤ 当前库存 ≤ 15,000`：库存偏低（临期）
- 🟢 当前库存 `> 15,000`：库存安全
