# 智造WMS - 仓储库存与智能补货预警系统

基于 Streamlit 的仓储库存管理工具，保留双向查询、库存看板、OCR 单据识别、一键演示数据和 CSV 快照存储。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

库存预警规则：

- 🔴 当前库存 < 10,000：紧急备货（高风险）
- 🟡 10,000 ≤ 当前库存 ≤ 15,000：库存偏低（临期）
- 🟢 当前库存 > 15,000：库存安全

OCR 页面文案为“上传出入库单据识别”。演示数据包含低于 10,000 的物料，可直接查看补货预警。
